# 디스코드 리뷰 데이터 분석 봇 (Discord Review Viewer)

디스코드 서버 내에서 사용자들이 남긴 감상평과 리뷰 데이터를 자동으로 수집하고 데이터베이스화하여, 편리하게 검색하고 통계를 확인할 수 있도록 돕는 디스코드 봇입니다. 

## 주요 기능

*   **리뷰 남기기 (`/리뷰남기기`)**
    *   제목, 생산자(가수/감독/작가 등), 내용, 평점을 입력하여 리뷰를 기록합니다.
    *   이미지를 첨부하거나, 첨부하지 않을 경우 제목을 기반으로 자동으로 관련 이미지를 가져와 예쁜 임베드 메시지로 보여줍니다.
*   **리뷰 검색 (`/리뷰검색`)**
    *   지금까지 서버에 쌓인 리뷰들을 페이지 단위로 넘겨가며 쉽게 조회할 수 있습니다. 
    *   제목과 생산자 정보를 함께 깔끔하게 보여줍니다.
*   **사용자 통계 조회 (`/통계`)**
    *   특정 사용자가 어떤 카테고리의 리뷰를 주로 남겼는지 분포도를 텍스트 프로그레스 바 형태로 보여줍니다.
    *   해당 사용자의 평균 평점 데이터를 한눈에 확인할 수 있습니다.
*   **과거 채팅 기록 불러오기 (`/기록불러오기`)**
    *   봇을 도입하기 전 채널에 남겨져 있던 `[제목 - 생산자] 평점/5` 형식의 메시지들을 최대 100개 단위씩 자동으로 긁어와 DB에 파싱하고 저장합니다.
    *   LLM API 비용 없이 **DuckDuckGo 검색 결과**를 바탕으로 음악, 영화, 도서, 장소 등의 카테고리를 똑똑하게 자동 분류합니다! 중복 데이터는 알아서 무시됩니다.

## 기술 스택

*   **Node.js**: 백엔드 런타임
*   **Discord.js (v14)**: 디스코드 봇 인터페이스 및 슬래시 명령어 처리
*   **기타**: 단순 파일 기반(`data.json`) 영속성 처리, DuckDuckGo 크롤링 기반 무과금 카테고리 분류(`fetch` API)

## 설치 및 실행 방법

1. 저장소를 클론합니다.
   ```bash
   git clone https://github.com/kimchunsik17/discord_review_viewer.git
   cd discord_review_viewer
   ```

2. 패키지를 설치합니다.
   ```bash
   npm install
   ```

3. `.env` 파일을 생성하고 다음 정보를 입력합니다.
   ```env
   DISCORD_TOKEN=당신의_디스코드_봇_토큰
   CLIENT_ID=당신의_디스코드_클라이언트_ID
   ```

4. 봇을 실행합니다.
   ```bash
   node index.js
   ```

## 파일 구조
* `index.js` - 봇의 메인 엔트리 포인트 및 이벤트/명령어 핸들링 로직
* `commands/` - `/리뷰남기기`, `/리뷰검색` 등 슬래시 명령어 로직 폴더
* `utils/dataStore.js` - 리뷰 데이터를 `data.json`에 저장하고 불러오는 DB 유틸리티
* `utils/smartHelper.js` - 무료 검색 엔진(DuckDuckGo)을 활용한 카테고리 자동 분류 및 Fallback 이미지 가져오기
